# stathis.com.gr

Static website of [Stathis](https://stathis.com.gr) — refrigerated & isothermal
vehicle conversions since 1961. Built with Astro; deployed to GitHub Pages on
every push to `main`. Migrated from WordPress in 2026 with URLs preserved.

- `CLAUDE.md` — editing rules and common tasks
- `src/content/` — all page content (Markdown, Greek + English)
- `parity/` — URL-parity safety net against the old site
- `export/` — archived export of the old WordPress site (provenance)
